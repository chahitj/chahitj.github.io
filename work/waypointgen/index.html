Ambiguous agricultural instructions

An instruction such as "traverse aisle 1, then 17, then 2 while avoiding water channels" mixes field-scale route order with nearby hazards. From a diagonal, ground-level view, the third tree can be hard to identify; a gap in vegetation can look like the end of a row. Counting visible plants alone is a brittle way to ground an instruction.

I led the global branch, where row and aisle starts, ends, gaps, and connectivity become a spatial graph that a Qwen-family VLM can use for waypoint generation. Kulbir Singh Ahluwalia focused more heavily on the local branch. We evaluated the pipeline on recorded agricultural data.

Global and local planning

I built the global branch that extracts crop-row structure from overhead imagery, builds a spatial graph, and uses a Qwen-family VLM to produce normalized 2D waypoints. The team's local branch projects RGB-D into a semantic BEV and evaluates MPPI trajectory candidates against the instruction.

Data, perception, and trajectory selection

Global and local constraint decomposition

Row order and destination sequence go to the overhead route planner; nearby obstacles and hazards go to local selection. An explicit aisle graph and row endpoints help resolve references such as a numbered tree when plants are missing or the egocentric view is ambiguous.

Global waypoint generation

I built the global pipeline that detects crop-row structure, converts rows and intersections into a spatial graph, and prompts a Qwen-family VLM to return waypoints in normalized overhead-image coordinates.

Local semantic planning

The team’s local branch projects RGB-D into a semantic BEV and uses MPPI to generate feasible local paths before language-conditioned selection. Kulbir led this branch and its final timing analysis.

Semi-supervised dataset generation

No ready-made dataset covered the farmer-style commands we needed. I worked on generating instructions at several abstraction levels and implemented a three-stage Qwen Code-as-Policies filter that rejected malformed or weakly grounded commands before training.

Edge-oriented model work

I investigated Qwen-family model choice, small-dataset finetuning, and quantization for lower-cost inference. The team ran parts of the local stack on a Jetson and identified the remaining integration work for end-to-end field operation.

Recorded-data evaluation

We evaluated language-conditioned target selection on recorded palm and citrus data against zero-shot VLM and graph-roadmap baselines. The experiments identified candidate selection and instruction grounding as the main limits.

Kulbir Singh Ahluwalia produced the final timing profile on a DGX Spark. In that team measurement, command-to-waypoint processing took about 12 s; VLM candidate selection accounted for 6.889 s, or 58.8%, while MPPI took 805 ms.

Failure analysis

Latency and remaining work

VLM selection remained the main latency bottleneck, and the project did not reach full end-to-end autonomous field deployment.

Five citrus prompt failures came from GPS-trace instructions without enough visual grounding. Multi-view fusion and thermal nighttime operation remained unfinished extensions.
